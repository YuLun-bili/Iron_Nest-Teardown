# Iron Nest - Teardown
### This is a fan-made recreation of [Iron Nest](https://store.steampowered.com/app/2950790/) in [Teardown](https://store.steampowered.com/app/1167630/)

Current objectives of this project includes:
#### Recreation:
- [ ] Recreation of core Iron Nest game mechanisms
- [ ] Recreation of the Iron Nest turret interiors
#### Improvements:
- [ ] Achieve more realistic ballistic trajectories
- [ ] Improve console operation logic for quicker and more accurate inputs
- [ ] Achieve more realistic allied & enemy units behaviour
#### Additions:
- [ ] Exterior of Iron Nest and small scene for it
- [ ] Achieve in-turret multiplayer
- [ ] Archive turret vs turret multiplayer
- [ ] New maps, missions and challenges

> [!IMPORTANT]
> This project **IS NOT** a complete or high similarity remake of Iron Nest in Teardown! Especially the story and lore of original game.
>
>  I (YuLun) am a fan of Iron Nest and I like the game very much. Yet it have some flaws and imperfections which are either unfortunately admitted by the devs that they can't change it, or deemed too complicated to be implemented in original game. Thus I chose to help myself out and probably others at the same time.
